# Overgrown theme — October 14, 2026

The artist requested a complete aesthetic change: vines throughout, a Stranger Things mood, and organic alternatives to square media cards. The visual reference was Netflix's [production-design interview](https://www.netflix.com/tudum/articles/the-secrets-behind-designing-the-multiverse-of-stranger-things): layered tendrils, painted surfaces, and an environment that feels overtaken. The website uses its own composition and generated artwork. No show imagery, logos, characters, or client associations are used.

`dist/overgrowth.css` contains the current design. Vines are decorative, pointer-transparent, and layered behind controls. The gallery uses varied asymmetric rounded portals with open captions, staggered placement, and restrained glowing rims. The same charcoal, bone, blue-shadow, and ember palette carries through the studio, contact area, dialogs, and footer. Mobile uses a lighter edge treatment and one portal per row. No decorative animation was added; the existing motion and preview controls retain their reduced-motion behavior.
